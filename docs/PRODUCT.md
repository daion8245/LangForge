## 1. 한 줄 정의

**LangForge는 Minecraft 모드 JAR과 리소스팩에서 언어 파일을 자동으로 찾아 번역하고, 게임에 바로 적용되는 리소스팩으로 내보내는 로컬 데스크톱 도구입니다.**

---

## 2. 해결하는 문제

### 2.1 현재 상황

한국어 모드팩을 만들려면 지금은 이렇게 해야 합니다.

```text
1. JAR 파일을 압축 해제 프로그램으로 연다
2. assets/ 안을 뒤져서 lang 폴더를 찾는다
3. en_us.json 을 텍스트 에디터로 연다
4. 값을 하나씩 복사해 번역기에 붙여넣는다
5. 결과를 다시 붙여넣는다
6. %s 나 §a 가 깨지지 않았는지 눈으로 확인한다
7. ko_kr.json 으로 저장한다
8. 리소스팩 폴더 구조를 손으로 만든다
9. pack.mcmeta 를 만들고 pack_format 숫자를 검색해서 채운다
10. ZIP 으로 압축한다 (폴더째 압축하면 게임이 인식하지 않는다)
11. 모드 200개면 1~10 을 200번 반복한다
```

### 2.2 이 과정이 실패하는 지점

| 실패 지점 | 왜 발생하는가 | 결과 |
|---|---|---|
| 언어 파일을 못 찾음 | 파일명 `Quark-4.0.jar` 과 내부 namespace `quark`·`zeta`·`emi` 가 다름 | 번역 누락 |
| JSON key 가 바뀜 | 번역기가 key까지 번역해버림 | 게임에서 텍스트가 통째로 사라짐 |
| 변수가 깨짐 | `%1$s died whilst trying to escape %2$s` 가 `%s님이 도망치다 사망` 이 됨 | 게임 크래시 또는 문자열 오류 |
| 기존 번역이 날아감 | 이미 있던 `ko_kr.json` 을 자동 번역으로 덮어씀 | 검수된 번역 손실 |
| 리소스팩이 인식 안 됨 | ZIP 안에 폴더가 한 겹 더 있음 / `pack_format` 이 버전과 안 맞음 | 게임이 팩을 무시 |
| 중간에 멈춤 | JSON 문법 오류 하나가 전체 작업을 중단시킴 | 처음부터 다시 |

### 2.3 LangForge 가 해결하는 것

```text
파일명이 아니라 assets/*/lang 실제 경로로 찾는다      → 누락 없음
key 는 절대 API 로 보내지 않는다                       → key 손실 0건
변수를 토큰으로 치환하고 멀티셋으로 검증한다            → 깨진 변수는 출력 전에 차단
기존 번역·사용자 수정을 자동 번역보다 우선한다          → 덮어쓰기 없음
pack.mcmeta 를 버전 프로필에서 자동 생성한다            → 인식 실패 없음
namespace 단위로 오류를 격리한다                        → 하나가 깨져도 나머지는 완주
```

## 3. 사용자

### 3.1 주 사용자 A — 개인 플레이어

> "모드 180개 넣은 모드팩을 하는데 아이템 이름이 전부 영어라 뭐가 뭔지 모르겠다."

| 항목 | 내용 |
|---|---|
| 환경 | Windows PC, `.minecraft/mods` 폴더에 JAR 파일 다수 |
| 기술 수준 | JSON 이 뭔지 모름. 리소스팩은 넣어본 적 있음 |
| 원하는 것 | mods 폴더를 통째로 넣고 버튼 한 번 |
| 참을 수 없는 것 | 설정 화면이 복잡한 것, 중간에 알 수 없는 오류로 멈추는 것 |
| 성공 = | 출력한 ZIP 을 resourcepacks 에 넣었더니 게임에서 한국어가 나옴 |

### 3.2 주 사용자 B — 모드팩 제작자 / 서버 운영자

> "우리 서버 모드팩 한글판을 배포해야 하는데, 모드가 업데이트될 때마다 새 키만 번역하고 싶다."

| 항목 | 내용 |
|---|---|
| 환경 | Windows PC, 모드 구성이 주기적으로 바뀜 |
| 기술 수준 | JSON·리소스팩 구조를 이해함. 번역 품질에 민감함 |
| 원하는 것 | 프로젝트를 저장해두고, 모드 추가 시 **새 키만** 번역. 용어를 통일. 배포용 통합 팩 하나 |
| 참을 수 없는 것 | 손으로 고친 번역이 다음 실행에서 사라지는 것, 어떤 키가 왜 실패했는지 모르는 것 |
| 성공 = | 모드 5개 추가 후 재실행 → 새 키 40개만 번역되고 기존 3,000개는 그대로 |

### 3.3 대상이 **아닌** 사용자

- 여러 명이 동시에 검수하는 번역 팀 (실시간 협업·권한 관리 없음)
- 자기 모드를 다국어로 출시하려는 모드 개발자 (소스 트리 통합·CI 연동 없음)
- 웹에서 쓰고 싶은 사용자 (MVP 는 로컬 데스크톱 전용)

> 이들을 배제하지는 않지만, 충돌하는 요구가 나오면 3.1 / 3.2 를 우선합니다.

## 4. 핵심 가치

우선순위 순서입니다. 아래로 갈수록 양보 가능합니다.

### 1순위 — 원본을 망가뜨리지 않는다

```text
key 는 변경하지 않는다        key 는 API 로 전송하지 않는다
변수와 서식 코드는 보존한다    검증 실패 항목은 저장하지 않는다
기존 번역은 덮어쓰지 않는다    입력 JAR 은 절대 수정하지 않는다
```

이 원칙이 깨지면 다른 모든 기능이 무의미합니다. 성능·편의성보다 항상 우선합니다.

### 2순위 — 파일 구조를 추측하지 않는다

모드 ID·파일명·폴더명으로 판단하지 않고, `assets/{namespace}/lang/{code}.json` 이라는 **실제 경로**만 봅니다. AI 는 파일 구조 판단에 관여하지 않습니다.

```text
AI / 번역 API 의 역할 = JSON value 문자열 하나를 번역하는 것. 그 이상 없음.
탐색 · 파싱 · 병합 · 검증 · 출력 = 전부 결정론적 프로그램 로직.
```

### 3순위 — 부분 실패가 전체 실패가 되지 않는다

namespace 단위로 오류를 격리합니다. 200개 모드 중 3개가 깨져 있어도 197개는 정상 출력됩니다.

### 4순위 — 무엇이 왜 그렇게 됐는지 보인다

모든 키는 9가지 상태 중 하나를 가지고, 그 이유를 화면에서 확인할 수 있습니다.

```text
대기 · 번역 중 · 새 번역 · 기존 번역 유지 · 캐시 재사용
검증 실패 · 원문 유지 · 확인 필요 · 빈 문자열 유지
```

### 5순위 — 다시 하지 않는다

프로젝트를 저장하고, 캐시를 재사용하고, 새 키만 번역합니다.

## 6. MVP 범위

### 6.1 MVP 정의

> **Windows 데스크톱에서, 여러 개의 모드 JAR 을 넣어 한국어 번역 리소스팩 ZIP 을 만들어 게임에 적용할 수 있다.**

이 문장이 성립하지 않으면 MVP 가 아닙니다.

### 6.2 MVP 에 포함

| 영역 | 포함 내용 |
|---|---|
| 플랫폼 | Windows 데스크톱 단독 |
| 입력 | JAR · ZIP 다중 선택, mods 폴더 통째로 추가, 압축 해제된 폴더 |
| 입력 안전 검사 | 확장자 · 크기 · 손상 · 경로 탈출 · 압축 폭탄 · 중복 해시 |
| 탐색 | `assets/*/lang/*.json` 전체 탐색, 다중 namespace, 발견된 언어 파일 목록 표시 |
| 원본 언어 | 프로젝트 기본 `en_us`, namespace 별 예외 지정, 원본 없을 때 대체 선택 UI |
| 대상 언어 | `ko_kr` 고정. 대상 언어 셀렉트는 표시하되 MVP 에서는 `ko_kr` 만 선택 가능 (데이터 구조는 다국어 허용) |
| JSON | UTF-8 · 문법 · 최상위 평탄 Object · 중복 key · 제어 문자 사전 검사. 중첩 구조는 지원하지 않는 구조로 표시하고 namespace 단위 격리 |
| 번역 | key/value 분리, value 만 전송, 배치 요청, 일시정지 · 재개 · 취소 · 실패 항목 재시도 |
| 번역 엔진 | **어댑터 인터페이스는 4종(DeepL·Gemini·Google·Papago) 기준으로 설계. MVP 는 Gemini 1종만 실제 구현** |
| 인증 | BYOK. Windows Credential Manager 보관, 화면 마스킹, 연결 테스트 |
| 변수 보호 | printf · 위치 지정 · 이스케이프 · `§` 서식 · HEX 색상 · `{}` · `${}` 토큰 치환/복원 |
| 검증 | 변수 멀티셋 비교, key 개수·목록 동일성, 빈 번역, JSON 문법 |
| 병합 | 기존 `ko_kr.json` 유지, 사용자 수정 최우선, 자동 덮어쓰기 금지 |
| 다중 모드 | 여러 JAR 을 한 프로젝트에서 관리, 트리에 동시 표시 |
| 충돌 | **감지하고 경고만** 표시 (해결 UI 는 1.0) |
| 편집 | 대조 편집 화면, 검색, 상태 필터, 직접 수정, 변수 비교 표시 |
| 출력 | 개별 JSON / 전체 경로 보존 JSON / 폴더형 리소스팩 / 통합 ZIP 리소스팩 |
| pack.mcmeta | 문서 작성 시점에 확정한 1.18.2 ~ 1.21.4 (12개 버전 프로필) 에서 `pack_format` 자동 결정. 최신 출시 버전을 자동 추가하지 않음 |
| 출력 전 검사 | 상태별 집계, 차단 조건 판정, 사용자 정책 선택 |
| 프로젝트 | 저장 · 다시 열기, 입력 파일 해시 기반 변경 감지 |
| 보고서 | `Translation_Report.md` 생성 |

### 6.3 MVP 에서 제외 (1.0 으로 미룸)

| 제외 항목 | 언제 |
|---|---|
| DeepL · Google · Papago 어댑터 구현 | 1.0 |
| namespace 충돌 **해결** UI (원문 비교·선택) | 1.0 |

| 다국어 대상 UI (`ja_jp`·`de_de`·`fr_fr` 선택) | 1.0 |
| pack.png 사용자 이미지 · 원본 모드 아이콘 추출 | 1.0 |
| Android 모바일 UI | 1.0 이후 별도 Phase |

## 7. MVP 성공 기준

MVP 는 **기술 기준**과 **실사용 기준**을 모두 통과해야 합니다. 하나라도 실패하면 MVP 미완성입니다.

### 7.1 기술 기준 — 실제 단일 모드와 Example Mode로 검증

사용자가 제공하는 실제 단일 모드 후보와 자체 제작 Example Mode를 함께 입력하여 측정합니다. JAR 150개 이상을 요구하는 별도 규모 게이트는 MVP 검증 범위에서 제외합니다.

| # | 기준 | 목표값 | 측정 방법 |
|---|---|---|---|
| T2 | namespace 탐색 누락 | **0건** | 수동으로 압축 해제해 센 `assets/*/lang` 개수와 일치 |
| T3 | key 손실 | **0건** | 원본 key 집합 == 출력 key 집합 |
| T4 | key 변형 | **0건** | 출력 JSON 의 모든 key 가 원본과 문자 단위 동일 |
| T5 | 변수 멀티셋 불일치가 출력에 포함됨 | **0건** | 출력 전 검사에서 전부 차단되거나 원문 유지 처리 |
| T6 | 기존 번역 손실 | **0건** | 입력에 있던 `ko_kr.json` 의 값이 자동 번역으로 바뀌지 않음 |
| T7 | 부분 실패 격리 | JSON 오류 namespace 가 있어도 **나머지 100% 완주** | 고의로 깨진 JAR 을 섞어 실행 |
| T8 | 중단 없는 완주 | 크래시 · 무한 대기 **0건** | 전체 실행 1회 |
| T9 | 처리 시간 | 키 **10,000개를 30분 이내** (API 응답 시간 제외 시 자체 처리 5분 이내) | 실행 로그 |
| T10 | UI 응답성 | 대형 ZIP 해제·파싱 중 UI 프레임 드랍 **없음** | isolate 분리 확인 |
| T11 | API 키 노출 | 로그 · 프로젝트 파일 · 보고서에 **0건** | 산출물 전수 grep |
| T12 | 재실행 증분 | 모드 5개 추가 후 재실행 시 **새 키만** 번역 대기 상태 | 상태 집계 확인 |

### 7.2 실사용 기준 — 게임에서 확인

| # | 기준 | 통과 조건 |
|---|---|---|
| U1 | 리소스팩 인식 | 출력 ZIP 을 `resourcepacks/` 에 넣으면 게임 내 목록에 정상 표시 (느낌표·회색 처리 없음) |
| U2 | 적용 | 활성화 후 인게임 아이템 · 블록 · GUI 텍스트가 한국어로 표시 |
| U3 | 변수 정상 동작 | 사망 메시지 · 툴팁 등 변수 포함 문자열이 게임에서 **깨지지 않고** 값이 채워짐 |
| U4 | 서식 코드 | `§` 색상 코드가 색으로 렌더링됨 (문자로 노출되지 않음) |
| U5 | 로그 청결 | 게임 로그에 리소스팩 관련 오류 · 경고 **0건** |
| U6 | 버전 호환 | 지원 범위 중 최소 3개 버전(예: 1.20.1 / 1.21.1 / 1.21.4)에서 U1~U5 통과 |

## 12. 용어

| 용어 | 정의 |
|---|---|
| namespace | `assets/{namespace}/lang/` 의 두 번째 경로 조각. 모드 ID 와 다를 수 있으며, 하나의 JAR 에 여러 개가 있을 수 있음 |
| 언어 파일 | `assets/{namespace}/lang/{code}.json` |
| 원본 언어 | 번역의 입력이 되는 언어. 프로젝트 기본값은 `en_us`, namespace 별로 예외 지정 가능 |
| 대상 언어 | 번역 결과를 저장할 언어. MVP 는 `ko_kr` |
| 번역 항목 | key 하나에 대응하는 단위. 원문·기존 번역·새 번역·상태·검증 결과를 가짐 |
| 보호 토큰 | `%s` · `%1$s` · `§a` · `\n` · `{0}` 처럼 번역기에 넘기기 전에 치환하고 번역 후 복원하는 문자열 |
| 멀티셋 비교 | 보호 토큰의 **종류와 개수**를 함께 비교하는 검증. 존재 여부만 보지 않음 |
| 프로젝트 | 여러 입력 파일과 설정·번역 상태를 함께 관리하는 작업 단위. 저장하고 다시 열 수 있음 |
| BYOK | Bring Your Own Key. 사용자가 직접 발급받은 API 키를 입력해 사용하는 방식 |
| pack_format | 리소스팩이 어느 Minecraft 버전용인지 나타내는 정수. `pack.mcmeta` 에 기록 |
